Metro Grid

2.5D Isometric Urban Transit Simulator • 100% Procedural Audio • WebAssembly

THE INFINITE TRANSIT LOOP • SELF-BALANCING 3-ASPECT SIGNALS

Metro Grid is a RollerCoaster Tycoon-style metro network builder. You lay tracks, stations, and concourse scenery across a 2.5D isometric city grid (64x32 dimetric tiles, 48x48 world). Commuters arrive at entrances, swipe through turnstiles, queue on platforms, and board your trains. They alight at the station matching their shape badge.

// Technical Specifications

  • Language: C++17 (-Wall -Wextra strict)
  • Rendering & Sound: Raylib 6.0 statically linked
  • Audio: 100% Procedural waveform synthesis (VVVF motor whine, chimes)
  • Web Build: Emscripten / WebAssembly (1280x720 60 FPS)
  • Map Geometry: 48x48 Grid, multi-level elevation viaducts & tunnels

// Core Mechanics

  • • 3-Aspect Automatic Block Signalling: Green/Yellow/Red separation
  • • Shape-Coded Riders: Square, Circle, Triangle, Cross archetypes
  • • Platform Overcrowd Timers: Dynamic dispatch triage
  • • Operating Modes: OPEN (Revenue), TEST RUN (Empty Loops), CLOSED
  • • Endless Metropolis: Unlockable sandbox after 1,500 riders

Void Protocol: Space Shooter

Kinetic 2D Space Combat • Inertia Dampening Controllers • Pixel Art Collision Loops

HIGH-VELOCITY CELESTIAL DOGFIGHTS

Void Protocol explores low-friction vector kinematics in Godot Engine. Maneuver through treacherous asteroid belts, engage alien raider fleets, activate directional warp gates, and master thrust-and-drift flight mechanics.

// Technical Highlights

  • Engine: Godot Engine (2D Physics & Vector Mathematics)
  • Controllers: Custom inertia dampening and momentum preservation
  • Collision: Frame-accurate polygon hit detection
  • Particles: Directional thruster exhausts and explosive debris
